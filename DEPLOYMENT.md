# HormonaCare Deployment Guide

## Render Web Service

Use the included `render.yaml` as a Render Blueprint, or create a Python web service manually with:

- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app -c gunicorn.conf.py`
- Health check path: `/api/health`
- Python version: `3.11.11`

The app binds to `0.0.0.0:$PORT`, which Render expects for web services.

## Required Environment Variables

Set these in Render before deploying:

- `DATABASE_URL`: Supabase Postgres connection string with `?sslmode=require`
- `SUPABASE_URL`: Supabase project URL
- `SUPABASE_PUBLISHABLE_KEY`: Supabase anon/publishable key
- `SECRET_KEY`: generated by Render if using `render.yaml`
- `FIELD_ENCRYPTION_KEY`: optional, but recommended for encrypted notes

Optional but recommended for stable Web Push subscriptions:

- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`

If the VAPID variables are blank, HormonaCare generates a local key at startup. That works for a demo, but existing browser push subscriptions may need to be recreated after a redeploy because Render's filesystem is not persistent.

## After First Deploy

1. Copy your Render URL, such as `https://hormonacare.onrender.com`.
2. Set `PUBLIC_BASE_URL` to that URL. The app also falls back to Render's `RENDER_EXTERNAL_URL`.
3. In Supabase Auth settings, add the deployed URL to allowed redirect URLs.
4. Open `/api/health` and confirm `"ok": true`.
5. Log in, go to Settings, and click `Test Notification`.

## Web Push Reminder Notes

Server push reminders work when:

- the Render service is awake/running,
- the browser has granted notification permission,
- the user's browser/device is online,
- reminders are enabled in HormonaCare.

Medication reminders are checked about 2 minutes before schedule. Appointment reminders are checked about 30 minutes before schedule.
The reminder scheduler scans about every 15 seconds by default.

On Render Free, the web service can spin down after 15 minutes without inbound traffic. While it is asleep, the reminder scheduler is not running. For a live reminder demo, open the deployed app shortly before the scheduled reminder time or use a paid always-on instance.
